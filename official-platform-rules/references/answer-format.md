# 回答格式

完成澄清和检索后按以下顺序回答：

1. **结论**：一句话直接回答。
2. **适用范围**：平台、国家/站点、主体来源、身份、店铺类型、履约方式、类目、项目、订单状态和事件日期。
3. **当前有效规则**：仅陈述检索到的当前版本。
4. **建议动作**：给出用户可以执行的下一步。
5. **官方依据**：文档标题、官方 URL、快照章节、发布/生效日期、有效期、最后核验时间。
6. **限制与例外**：说明账号专属、范围缺失、官方冲突或实时刷新失败。
7. **知识库状态**：展示 `complete` 或 `partial`、已覆盖/缺失主题、待复核域名和过期/失败来源。

每个实质性结论必须能对应至少一个官方来源。若检索结果为空，使用：

> 官方资料暂未确认。当前官方来源库没有足够证据支持确定性结论。

不要只说“以后台为准”。如需后台信息，明确说明缺少哪一项官方通知或账户范围。

历史事件必须展示 `as_of_date` 以及命中版本的 `valid_from`、`valid_to`。
若有效期由首次观察时间推定而非官方日期确定，必须明确说明该限制。
