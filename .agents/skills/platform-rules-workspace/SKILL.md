# 平台规则知识库入口

1. 完整读取项目根目录的 `AGENTS.md`。
2. 继续完整读取项目根目录 `official-platform-rules/SKILL.md`（从本文件的相对路径为 `../../../official-platform-rules/SKILL.md`）并按其中流程执行。
3. 仅在本项目内管理配置、快照、数据库、导入和输出；不得访问兄弟项目。
4. 仅使用官方一手来源，记录市场、主体、履约方式、规则日期与核验时间。
5. 证据不足、冲突或页面仅返回动态空壳时明确拒绝断言，不得用第三方资料补全。
